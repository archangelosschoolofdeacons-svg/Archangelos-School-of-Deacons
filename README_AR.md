# Archangelos School of Deacons | مدرسة أرشى أنجيلوس للشمامسة

تطبيق ويب تقدّمي يعمل بالعربية والإنجليزية، ويختار لغة الجهاز افتراضيًا مع إمكان التبديل اليدوي إلى لغة التطبيق وحفظ هذا الاختيار مستقلًا عن لغة الجهاز. يحتوي على الصفحة الرئيسية، المراحل الدراسية السبع، المواد الثلاث، الفصول الثلاثة، عارض المواد، ولوحة أولية لإدارة محتوى المكتبة، مع مظهر فاتح وداكن وخيار اتباع إعداد الجهاز.

## تشغيل التطبيق على جهازك

يجب فتح التطبيق من خادم محلي أو من موقع يستخدم HTTPS حتى يعمل تثبيت التطبيق وService Worker. من مجلد المشروع شغّل:

```powershell
python -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح. ويمكن استخدام إضافة Live Server في VS Code بدلًا من ذلك.

## تثبيت التطبيق

- Android: افتح الموقع في Chrome واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- iPhone وiPad: افتح الموقع في Safari، اضغط «مشاركة»، ثم اختر «إضافة إلى الشاشة الرئيسية».
- الكمبيوتر: استخدم رمز التثبيت في شريط العنوان أو قائمة المتصفح.

يجب نشر الموقع على عنوان HTTPS عام لتثبيته على أجهزة المستخدمين. أي استضافة ملفات ثابتة تدعم HTTPS مناسبة كبداية.

## إضافة المواد التعليمية

1. افتح «إدارة المحتوى» من تذييل الصفحة أو انتقل إلى `#/admin`.
2. اكتب عنوان المادة، وحدد المرحلة والمادة والفصل الدراسي ونوع المحتوى.
3. ارفع ملفًا صوتيًا أو فيديو أو PDF أو صورة، أو أضف رابطًا مباشرًا. روابط YouTube تعمل داخل مشغّل الفيديو.
4. احفظ المادة؛ ستظهر تلقائيًا في القسم الذي اخترته.

يمكن تعديل المادة أو حذفها من قائمة «المواد المضافة». ملفات الجهاز تحفظ في IndexedDB في المتصفح الذي رفعها، وتبقى متاحة دون اتصال على ذلك الجهاز. روابط YouTube والروابط الخارجية تحتاج إلى اتصال بالإنترنت.

بعد حفظ مادة جديدة، تظهر رسالة داخل التطبيق، ويمكن تفعيل إشعار المتصفح من قائمة المظهر واللغة. يلزم السماح بالإشعارات، كما يلزم تشغيل الموقع عبر HTTPS (أو localhost أثناء التطوير). في هذه النسخة المحلية يصل الإشعار إلى المتصفح الذي أضاف المادة فقط؛ لإخطار الطلاب على أجهزتهم المختلفة يلزم ربط التطبيق بخادم مشترك وخدمة Web Push.

## ملفات التطبيق

- `index.html`: هيكل الصفحة واللغة العربية واتجاه RTL.
- `styles.css`: الهوية البصرية والتجاوب مع الهاتف والكمبيوتر.
- `app.js`: التصفح ومكتبة المحتوى ولوحة الإدارة.
- `localization.js`: نصوص العربية والإنجليزية والترجمة حسب لغة الجهاز أو الاختيار اليدوي.
- `manifest.json`: اسم التطبيق وأيقوناته وخصائص التثبيت.
- `manifest-en.json` و`manifest-ar.json`: اسم التطبيق المثبّت حسب اللغة المختارة.
- `sw.js`: تخزين واجهة التطبيق الأساسية للعمل دون اتصال.
- `assets/logo.png` و`assets/icons/`: الشعار وأيقونات التثبيت.

## ملاحظات النشر

هذه نسخة أولية من جهة العميل. لوحة المحتوى لا تتضمن تسجيل دخول، وتخزينها محلي لكل متصفح؛ لذلك لا تستخدمها لإدارة مواد سرية أو لإدارة مشتركة بين خدام متعددين. للنشر العام مع عدة مسؤولين، أضف مصادقة وصلاحيات وخادمًا وقاعدة بيانات وتخزين ملفات مثل Firebase أو خدمة خلفية مكافئة. الإعلانات في الصفحة أمثلة تعريفية، وتُحدّث من بيانات المدرسة قبل النشر.

التخزين دون اتصال يشمل ملفات التطبيق الثابتة والمواد المرفوعة من الجهاز نفسه. المحتوى الذي يعتمد على رابط خارجي يحتاج إلى الإنترنت، وقد يختلف عرض PDF المضمّن بحسب المتصفح.
