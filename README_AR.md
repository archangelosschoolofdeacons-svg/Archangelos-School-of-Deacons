# Archangelos School of Deacons | مدرسة أرشى أنجيلوس للشمامسة

تطبيق ويب تقدّمي يعمل بالعربية والإنجليزية، ويختار لغة الجهاز افتراضيًا مع إمكان التبديل اليدوي إلى لغة التطبيق وحفظ هذا الاختيار مستقلًا عن لغة الجهاز. يحتوي على الصفحة الرئيسية، المراحل الدراسية السبع، المواد الثلاث، الفصول الثلاثة، عارض المواد، ولوحة إدارة محتوى محمية، مع مظهر فاتح وداكن وخيار اتباع إعداد الجهاز.

## تشغيل الخادم المشترك محليًا

يتطلب الخادم Python 3.10 أو أحدث. افتح PowerShell في مجلد `archangelos-pwa`، ثم أنشئ كلمة مرور قوية وشغّل:

```powershell
$env:ARCHANGELOS_ADMIN_USERNAME = "admin"
$env:ARCHANGELOS_ADMIN_PASSWORD = "ضع-هنا-كلمة-مرور-طويلة-وفريدة"
python server.py
```

افتح `http://localhost:8000`. سجّل الدخول من «إدارة المحتوى»؛ لا توجد كلمة مرور افتراضية. يقبل الخادم أكثر من مسؤول عبر متغير `ARCHANGELOS_ADMIN_USERS` بصيغة JSON، مثل `{"admin":"كلمة-مرور-طويلة-أولى","teacher":"كلمة-مرور-طويلة-ثانية"}`.

تُحفظ قاعدة البيانات والملفات المرفوعة في مجلد `outputs/archangelos-data` بجوار مجلد التطبيق. غيّر مكان الحفظ بتعيين `ARCHANGELOS_DATA_DIR` قبل تشغيل الخادم، واحفظ نسخة احتياطية من هذا المجلد دوريًا.

لا تستخدم `python -m http.server` أو تفتح `index.html` مباشرة لإدارة المحتوى؛ هذان الوضعان لا يشغّلان واجهة الخادم. يظل فتح الملف مباشرة متاحًا لمعاينة بيانات المتصفح القديمة فقط.

## تثبيت التطبيق

- Android: افتح الموقع في Chrome واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- iPhone وiPad: افتح الموقع في Safari، اضغط «مشاركة»، ثم اختر «إضافة إلى الشاشة الرئيسية».
- الكمبيوتر: استخدم رمز التثبيت في شريط العنوان أو قائمة المتصفح.

يجب نشر الموقع على عنوان HTTPS عام لتثبيته على أجهزة المستخدمين. أي استضافة ملفات ثابتة تدعم HTTPS مناسبة كبداية.

## إضافة المواد التعليمية

1. افتح «إدارة المحتوى» من تذييل الصفحة أو انتقل إلى `#/admin`.
2. اكتب عنوان المادة، وحدد المرحلة والمادة والفصل الدراسي ونوع المحتوى.
3. ارفع ملفًا صوتيًا أو فيديو أو PDF أو صورة، أو أضف رابطًا مباشرًا. روابط YouTube تعمل داخل مشغّل الفيديو.
4. احفظ المادة؛ يرفع الخادم الملف ويُظهر المادة لكل زوار الموقع على الأجهزة المختلفة.

يمكن تعديل المادة أو حذفها من قائمة «المواد المضافة». ملفات الجهاز تحفظ على الخادم المشترك، بينما تبقى إعدادات المظهر واللغة خاصة بكل متصفح.

تعمل المزامنة بين الأجهزة عندما يكون التطبيق والخادم منشورين على عنوان مشترك يمكن لجميع الأجهزة الوصول إليه. `localhost` للاختبار على جهاز الخادم فقط. للنشر على الشبكة أو الإنترنت، استخدم استضافة Python مناسبة أو خادم المدرسة، واضبط `ARCHANGELOS_HOST=0.0.0.0` عند الحاجة، وضع الموقع خلف HTTPS. عند إنهاء HTTPS على وكيل عكسي، عيّن `ARCHANGELOS_SECURE_COOKIE=1`.

تتحدّث المواد المنشورة تلقائيًا أثناء فتح التطبيق، ويظهر إشعار عند إضافة مادة جديدة. إشعار النظام يعتمد على سماح المستخدم وإعدادات المتصفح؛ الإشعارات الفورية عندما يكون التطبيق مغلقًا تتطلب إضافة Web Push وبيانات VAPID.

## ملفات التطبيق

- `index.html`: هيكل الصفحة واللغة العربية واتجاه RTL.
- `styles.css`: الهوية البصرية والتجاوب مع الهاتف والكمبيوتر.
- `app.js`: التصفح ومكتبة المحتوى ولوحة الإدارة والاتصال بالخادم المشترك.
- `server.py`: خادم HTTP ومصادقة المسؤولين وواجهة API وقاعدة SQLite ورفع الملفات.
- `localization.js`: نصوص العربية والإنجليزية والترجمة حسب لغة الجهاز أو الاختيار اليدوي.
- `manifest.json`: اسم التطبيق وأيقوناته وخصائص التثبيت.
- `manifest-en.json` و`manifest-ar.json`: اسم التطبيق المثبّت حسب اللغة المختارة.
- `sw.js`: تخزين واجهة التطبيق الأساسية للعمل دون اتصال.
- `assets/logo.png` و`assets/icons/`: الشعار وأيقونات التثبيت.

## ملاحظات النشر

يخزن التطبيق جميع المواد المنشورة علنًا، ويتطلب تسجيل دخول لإضافتها أو تعديلها أو حذفها. لا تفتح منفذ الخادم للعامة مباشرة دون HTTPS؛ استخدم وكيلًا عكسيًا أو منصة استضافة موثوقة، واضبط كلمة مرور مستقلة لكل مسؤول. الإعلانات في الصفحة أمثلة تعريفية، وتُحدّث من بيانات المدرسة قبل النشر.

يخزن التطبيق واجهته الأساسية وبعض الملفات التي سبق فتحها للعمل دون اتصال. تحديث المواد وإدارتها يتطلبان اتصالًا بالخادم، والمحتوى الذي يعتمد على رابط خارجي يحتاج إلى الإنترنت. وقد يختلف عرض PDF المضمّن بحسب المتصفح.
